# Youth-computing
Competitive Dev — Salon Ivo Egnana (Youth Computing)
Mai 2026
Participant au concours “Competitive developmnent” du salon tech Ivo Egnana organisé par Youth Computing , auquel nous avons developpé une application de signalement des incidents qui peuvent arriver dans la vie quotidien comme des panneaux cassés ou des cables électriques coupés où l’utilisateur prends en photo et marque l’incident sur une map visible au grand public et sont directement alerté de l’incident.
Utilisant React-vite et tailwindcss pour le frontend avec strapi pour le backend
